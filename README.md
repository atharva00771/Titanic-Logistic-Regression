## 🌟 Project Overview

This project focuses on predicting whether a passenger **survived the Titanic disaster** using a **Logistic Regression** machine learning model.

The project includes data preprocessing, exploratory data analysis, model training, prediction, evaluation, and visualization.

---

## 🎯 Objective

> **To build a Machine Learning classification model that predicts Titanic passenger survival based on passenger-related features.**

## 📂 Dataset

The project uses the **Titanic Dataset**, containing passenger information such as:

- 👤 Passenger details
- 🎫 Passenger Class
- ⚧️ Gender
- 🎂 Age
- 💰 Fare
- 👨‍👩‍👧 Family information
- 🛟 Survival Status

### 🎯 Target Variable

| Value | Meaning |
|---|---|
| `0` ❌ | Did Not Survive |
| `1` ✅ | Survived |
